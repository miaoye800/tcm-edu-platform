## 2. 流光只走已通段

旧实现取「第一个已亮穴 → 最后一个已亮穴」的整段路径。中间没学的穴位也会被光球
穿过——视觉上等于宣布"这段通了"，而用户明明只学了两头。

改成复用 `buildLearned` 已经算好的**连续段**（相邻两穴都 lit 才算一段）：

```ts
// buildLearned() 末尾存起来，rebuildFlow 直接取用
const runs = learnedRuns
```

`buildLearned` 是判断"哪些穴亮了"的唯一出口，流光跟着它走就不会出现两套判定。

## 3. L2 刻度：点了要有三件事同时发生

```
点刻度 → activeTickId 换人（右侧抽屉跟着换正文）
       → 相机不动（已经在特写，再飞一次是噪音）
       → 地址栏 ?focus=<node_id> 跟着走（可分享、可刷新还原）
```

相机不动的理由值得写下来：**五十个刻度挨个点过去是 L2 的常态操作**。每点一次都
`flyTo` 的话，台面会持续抖动，而用户此刻要的是"换一条正文"，不是"换一个机位"。

但地址栏必须同步——`?focus=` 是这个位置唯一能被分享、能被刷新还原的表达。
用 `router.replace` 不用 `push`：这是"我在看哪一条"，不是一次页面跳转；
用 `push` 会让后退键变成"退到上一条知识点"，退十几下才出得去。

## 4. 一个回声问题：点一下抖两下

点刻度 → emit `focus-node` → 父级 `router.replace` → `watch(route.query.focus)` →
又调回 `selectByNode` → **再飞一次相机**。

闸门放在 `selectByNode` 开头：

```ts
if (activeTickId.value === nodeId && view.value === 'acupoint') return
```

## 5. 深链的竞态：目录还没到就丢了

`/path?focus=…` 是视图在 `onMounted` 里推给场景的，而经脉目录是异步拉的
（几百 KB）。目录没到，`sections` 是空的，`selectByNode` 找不到小节就静默返回——
表现是「点了在地图上看，页面停在全身态，什么也没发生」。

修法：找不到先记下来，`loadAtlas` 收尾时再落一次。

```ts
if (!section) { pendingFocus = nodeId; return }   // 目录没到
...
atlas.value = await fetchAtlas(layer)
if (pendingFocus) { const id = pendingFocus; pendingFocus = ''; selectByNode(id) }
```

**这条是实拍抓出来的**：`capture-meridian-ticks.mjs` 第一步就是深链，超时 60 秒
等不到 `.tick-point`。静态检查和单元测试都发现不了——它们不加载真实的异步目录。

## 6. 契约断言（防回归）

```js
// 流光必须复用已学连续段，不许再自己算首尾
assert.match(curves, /const runs = learnedRuns/)

assert.match(scene, /@open="selectTick"/)

// 回声闸门
assert.match(scene, /if \(activeTickId\.value === nodeId && view\.value === 'acupoint'\) return/)
// 地址栏用 replace
assert.match(view, /router\.replace\(\{ query: \{ \.\.\.route\.query, focus: nodeId \} \}\)/)
assert.doesNotMatch(view, /router\.push\(\{ query: \{ \.\.\.route\.query, focus:/)
```

## 7. 实拍怎么跑

```bash
# L2 刻度（headless 足够，验的是 DOM 与 URL）
node scripts/capture-meridian-ticks.mjs

# 已学段与流光（必须真 GPU，headless 走 SwiftShader，光照与辉光都不作数）
HEADED=1 node scripts/capture-meridian-learned.mjs
```

`capture-meridian-learned.mjs` 会从图里挑"挂得最多"的那条经，取**中段连续四穴**
各学掉一个知识点，再拍全身与特写。挑中段不是讲究：首尾两穴常在会阴、面部这些
拍不到的角落，而只学两个穴的段太短，金色连线看不出来（第一版就是这么白拍的）。
