# P9 验收记录 · 体表皮肤 + 一具身体装全部学科

日期：2026-11-12
范围：`frontend/src/components/meridian/`、`backend/app/meridian/{assign,store,authoring}.py`、`backend/app/api/meridian.py`

这一轮处理两个用户直报的问题：

1. 腹部与手臂的肌肉「稀疏、撕裂、看着恶心」，问能不能换成真实皮肤；
2. 同一个穴位能代表不同学科，与「一具身体装全部学科」的设计不符。

---

## 1. 体表：肌肉默认关，皮肤成为默认的那具身体

### 1.1 诊断

不是分辨率不够，是**肌肉层本身是体素简化出来的**。

`asset.py` 用 `voxel_cluster(cell=7.5mm)` 把 BodyParts3D 的 muscular 系统合成一层
（`muscle 1.38 MB`）。薄肌腹在这个格距下被磨穿，肌群之间又没有筋膜填充，于是
凑到章节视距（1.25 m）就是一块块断开的红肉。补面补不回来——缺的不是面，是被
简化掉的解剖结构。

同时皮肤层当时是 `MeshBasicMaterial + opacity 0.028`，即一层几乎看不见的薄雾，
所以画面上看到的就是肌肉。

### 1.2 决定：皮肤是主体，肌肉是「剥皮观察」的第二层

理由不是好看，是**几何一致性**：

- 362 个穴位坐标由上游人工标定并**吸附在皮肤（FJ2810）三角形上**，连
  `skin_tri + skin_bary` 都落了库；
- 经脉折线同样走体表；
- 所以"穴位在哪"本来就定义在皮肤上。画肌肉，等于把落点画在里面一层。

### 1.3 改动

| 文件 | 改动 |
| --- | --- |
| `config/meridian-atlas.json` | `skin` 层 `opacity: 1.0`、`color: #b3907c`、`roughness: 0.86`，新增 `ghost_opacity: 0.05` 与三平面纹理参数；`muscle.default` 与 `quality.*.muscle` 改为 `false` |
| `components/meridian/BodyMesh.vue` | 皮肤材质 `MeshBasicMaterial` → `MeshStandardMaterial` + 低频三平面斑驳 + 轻起伏；`applySkinMode()` 让皮肤的不透明度跟着肌肉层走（开肌肉 → 退成 0.05 薄雾，关肌肉 → 实心） |
| 同上 | 皮肤开启 `polygonOffset`（factor/units = 1）：经脉线与穴位环都贴在皮肤表面上，同深度会 z-fighting 被切成虚线，把皮肤往深度里推一格即可 |
| 噪声 GLSL | 抽成 `NOISE_GLSL` 常量，肌肉与皮肤共用（两者都受"无 UV"约束，只是频率差两个数量级） |

### 1.4 实拍

- `.tmpverify/skin/10-closeup-skin.png` —— 穴位特写（0.62 m）：体表连续完整，
  肤色自然，经脉线与穴位环清晰压皮，无 z-fighting、无锯齿闪烁。
- `.tmpverify/skin/11-closeup-muscle.png` —— 同机位勾选肌肉：胸口与腹部可见
  明显空洞与拉丝，**复现了用户截图的现象**，确认根因判断成立。

## 2. 一具身体装全部学科：一穴一节

### 2.1 诊断

旧实现给每门课**各跑一遍** `assign_sections`，每次都新建 `ChannelCursor`，于是每门课
都从手太阴肺经的第一个穴位（中府）开始排。结果：

| | 第 1 节 | 第 2 节 |
| --- | --- | --- |
| 中药学 | 中府 | 云门 |
| 中医内科学 | 中府 | 云门 |
| 方剂学 | 中府 | 云门 |

身上一个「中府」同时是 6 门课的第 1 节——用户看到的就是"同一个穴位代表不同学科"。
而计划 §3.2 的容量结论是拿**六门课合计的 293 节**去比**全身 362 穴**（"370 < 409，
一穴一节装得下"），说明本意是全局一穴一节。实现偏离了设计。

### 2.2 取舍（已与用户确认）

一穴一节之后，五条经装不下：

| 经脉 | 容量 | 六科合计需求 |
| --- | --- | --- |
| 手太阴肺经 | 11 | 30 |
| 手少阴心经 | 9 | 23 |
| 足厥阴肝经 | 14 | 20 |
| 任脉 | 24 | 35 |
| 足少阴肾经 | 27 | 32 |

合计溢出 55–62 节，只能沿流注顺序顺延到邻经。**"穴位全局唯一"与"每科都严格
按归经落位"不可兼得**，用户选择前者。

### 2.3 分配顺序按「归经依赖度」

谁先取谁保住语义，所以顺序不是学科编号：

1. `acup` 针灸学——节名就是"某经某穴"，落错经是内容错误，最先取；
2. `internal` 中医内科学——肺系/心系/脾胃病证，脏腑归经是骨架；
3. `herb` 中药学——各论按功效归经；
4. `formula` 方剂学——按功效归，稍松；
5. `diagnosis` / `basic`——理论课，章是"阴阳五行/藏象/四诊"，归经本就带象征性，
   让它们吸收顺延最不伤内容。

实测四种顺序，总保留率都在 228–232 之间；这个顺序把损失从「内科学只剩 44%」
挪到「中基/中诊吸收」，内容上更划算。

### 2.4 实测结果

```
全学科分配：293 节 / 293 个不同穴位
    acup        32 节      internal    54 节
    herb        65 节      formula     76 节
    diagnosis   28 节      basic       38 节
已整体替换 map_section：293 行
```

- 293 节 ↔ 293 个不同穴位，`slot_ord` 全部为 1（无任何复用）；
- 余 69 个穴位未占用（362 − 293）；
- 归经语义：231 节留在原经（79%），62 节顺延。

## 4. 已知边界

- **用户已有的学习进度会换位置**：`user_path_state` 记的是知识点 id，知识点挂在哪一节、
  哪一节挂哪个穴位都变了，所以"学过的点"在新图上会出现在别处。这是重建地图的必然结果，
  不是 bug。
- 顺延的 62 节（21%）在教科书意义上不在对应经脉上。针灸学与中药学各自 100% 保住；
  内科学 53/54、方剂 57/76、中基 20/38、中诊 12/28。
- 肌肉层保留但默认关：学习时用皮肤，讲解剖时勾「肌肉」。
